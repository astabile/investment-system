# RUNBOOK

## Daily (Optional)
- Run the system after market close
- Review market regime
- Review current holdings
- Take no action

## Monthly (Primary)
- Run the system
- Check for regime change
- Check asset eligibility
- Decide whether to rebalance
- Log decision and reasoning

## When Not to Act
- If regime unchanged
- If no rule violation
- If discomfort is the only reason

## Mandatory Question Before Any Action
"Which written rule justifies this action?"
If none exists, do nothing.
